程序运行的k230上（固件库位cv.lite,固件库不同会报错程序），可以准确识别黑色矩形框，并计算出矩形框的中心坐标  
脱机调阈值版需要K230装有触摸屏，运行程序后，按下自带按键，可以进入调阈值模式，可以通过滑动4个参数的滑块来调整阈值参数，点击保存可以保存在K230的文件系统中（重新上电后使用的参数是修改后的参数）     
主要参数：  
L_min   
L_max   
这两个参数是识别黑色矩形框的灰度阈值，通过调整这个两个参数来准确识别不同颜色矩形框  
MIN_AREA    
MAX_AREA    
这两个参数是识别矩形框的最小面积和最大面积，通过调整这两个参数可以过滤一些环境影响
